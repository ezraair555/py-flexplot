Basics

The Grammar of flexplot

flexplot builds plots from three components: a formula, a dataset, and automatic geom selection. The formula determines what goes where; flexplot picks the right visual marks.

outcome ~ predictor + color | panel_col + panel_row
ComponentRole
outcomeY-axis variable
predictorX-axis variable
color2nd predictor → colors/symbols
|Separator for paneling
panel_col1st given → column facets
panel_row2nd given → row facets
Max 2 given variables (row + column). 3+ → error.

Complete Template

flexplot( outcome ~ predictor + color | panel_col + panel_row, data = dataframe, method = "auto", # "lm" | "loess" se = TRUE, # CI band ghost.line = NULL, # "black" for ref bins = NULL, # bin numeric given spread = NULL, # "quartiles" jitter = c(.1, 0) # width/height )

required: formula, data
optional: method, se, ghost.line, bins, spread, jitter

Quick Examples

flexplot(satisfaction ~ communication + separated | gender + interests, data = relationship_satisfaction)
# Histogram (intercept-only) flexplot(satisfaction ~ 1, data = df)
# Bar chart (categorical) flexplot(gender ~ 1, data = df)
# Ghost line cross-panel flexplot(y ~ x | group, data = df, ghost.line = "black")

Python Port

Python py-flexplot uses plotnine + statsmodels.

from pyflexplot import flexplot import statsmodels.formula.api as smf mod = smf.ols("y ~ x1", data=df).fit() visualize(mod)

Paneling (Faceting)

Given VarsLayout
1facet_wrap(~v)
2facet_grid(row~col)
3+Error (max 2)
flexplot(y ~ x | group, data = df) flexplot(y ~ x | g1 + g2, data = df)

Use bins = 3 to discretize numeric given vars.

Ghost Lines

ghost.line = "black" overlays a reference line from the full model across all panels.

flexplot(y ~ x | group, data = df, ghost.line = "black", se = FALSE)

Advanced Visualization

Added Variable Plots

Partial regression plot — residualizes out other predictors.

added.plot(satisfaction ~ communication + separated | gender, data = df, method = "polynomial", se = FALSE)
Use for linearity checks, outlier detection, multicollinearity diagnosis.

Visualizing Fitted Models

Pass a fitted model to visualize().

mod = lm(satisfaction ~ communication * separated, data = df) visualize(mod)

Supports: lm, glm, any model with predict(). Produces predicted-vs-actual and diagnostic plots.

Comparing Model Fits

Overlay two models visually.

full = lm(y ~ x * z, data = df) reduced = lm(y ~ x + z, data = df) compare.fits(y ~ x | z, data = df, full, reduced)
Blue = model 1, Red = model 2.

Neural Networks (flex_nn)

Drop torch.nn.Module or keras.Model into the pipeline.

fit = NeuralNetFit(model, X_train, y_train, predictor_names=["x1"], response_var="y") visualize(fit, data=test_df) permutation_importance(fit)

Backends: torch (default), Keras 3.
